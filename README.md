# h3max.info — H3 Max Hub

The navigation hub for **MiniMax H3 Max**: official links, fal.ai APIs, open weights, pricing, guides and live projects.

Live site: https://h3max.info

## Stack

Plain static HTML, no build step. Deployed on Vercel from this repository; every push to `main` goes live.

```
index.html    # the whole site (v1 is a single page)
favicon.svg
robots.txt
sitemap.xml
vercel.json   # clean URLs + security headers
```
